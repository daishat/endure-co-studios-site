Monster Daycare

Active development · For the Run Project

What is Monster Daycare?

Monster Daycare is a character-driven management game about caring for supernatural infants. Their personalities and needs create a mix of humor, caregiving decisions, and daycare-management challenges.

Design direction

The project explores how character personalities and player decisions can make caring for a group of little monsters engaging and funny.

Current development stage

The game is being developed for the Run Project. Genuine screenshots, gameplay examples, and more detailed design materials will be added when ready.

This page is a development overview. It does not represent a released game or a playable demonstration. Public access has not been announced.
